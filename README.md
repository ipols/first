# Léman Search Experiment

A public web-search retrieval experiment by **Iskander Pols**.

This page contains synthetic test data for checking whether an AI assistant can find a public source through web search and retrieve its current contents. It is not a business listing, a commercial offer, or a password.

## What the experiment measures

A successful name-led search returns the exact verification code and revision, with a citation to this page, without having been supplied the page address or the code in the test conversation.

Retrieving this page after receiving its address tests direct access only. It does not demonstrate discovery through search. Publication does not establish indexing or guarantee discovery.

A later revision can replace the code to test whether subsequent searches retrieve the updated record. Git history preserves the earlier records for comparison.
